## 🚀 About me

State Engineer in Computer Engineering (**ENSA Agadir**) and **Oracle Certified Professional, Java SE 17 Developer**.

I have shipped production software for SaaS companies in Morocco and France (company names kept confidential), in Scrum teams with backend, front-end and mobile engineers, often working directly with the client:

- **Employee-engagement SaaS:** a carpooling module built end to end (11 Flutter screens, Node.js API, PostGIS corridor matching, self-hosted OSRM routing, HMAC-signed QR check-in), plus Events and dynamic Forms modules in Flutter + Firebase.
- **Enterprise intranet portal:** Next.js + NestJS + Keycloak SSO, with the AWS infrastructure written in Terraform (VPC, ALB, ECS, ECR, RDS, WAF, CloudWatch) across Dev, Staging and Prod.
- **Restaurant management SaaS:** kitchen display, self-order kiosk and customer display. Flutter app with offline-first sync and PubNub real-time chat, Java 21 / Spring Boot backend with ~200 endpoints and 2,000+ automated tests.
